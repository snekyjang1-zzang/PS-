# 모션그래픽 키트 v4 사용 안내

## 이게 뭔가요
대본을 주면 Claude Code 가 음성과 자막을 만들고, **내가 정한 그림 스타일로** 그림을 생성하고, 장면을 짜서 **자막·배경음까지 들어간 완성 영상 한 편**을 만들어 주는 작업 폴더입니다.

## 준비물
| 무엇 | 어디서 | 필수 |
|---|---|---|
| Python 3.10 이상 | https://www.python.org/downloads/ (윈도우는 설치 첫 화면에서 **"Add python.exe to PATH" 체크**) | 필수 |
| Claude Code | 안내받은 방법으로 설치하고 로그인 | 필수 |
| 구글 AI 스튜디오 API 키 | https://aistudio.google.com/apikey | 필수 (목소리, 받아쓰기 검사) |
| fal.ai API 키 | https://fal.ai/dashboard/keys | 필수 (그림 생성) |
| 일레븐랩스 API 키 + 보이스 ID | https://elevenlabs.io/app/settings/api-keys | 선택 (일레븐랩스 목소리, 배경음·효과음) |

API 사용료는 각자 계정에서 나갑니다. 10분 영상 한 편에 그림 60~80장 정도가 기준입니다.

## 시작하기 (처음 한 번)
1. 압축을 풀어 `mg-pipeline` 폴더를 찾기 쉬운 곳에 둡니다. (윈도우 예: `C:\work\mg-pipeline`)
2. 폴더 안의 **`API키_양식.txt`** 를 열어 등호 뒤에 본인 키를 붙여 넣고 저장합니다.
3. 이 폴더에서 Claude Code 를 엽니다.
4. **`시작_프롬프트.txt`** 의 점선 아래 내용을 복사해 Claude Code 에 붙여 넣습니다.

그러면 Claude 가 설치 → 키 등록 → 채널 질문 → **그림 스타일 정하기** → 첫 영상 순서로 진행합니다.
(설치를 직접 하고 싶으면 윈도우는 `setup.bat`, 맥은 `setup.command` 를 더블클릭해도 됩니다.)

> 키는 채팅창에 붙여 넣지 마세요. `API키_양식.txt` 파일로만 전달하고, 등록이 끝나면 그 파일은 지우세요. 키는 폴더 안의 `.env` 파일에만 저장됩니다. 이 폴더를 남에게 줄 때는 `.env` 를 빼고 주세요.

## 그림 스타일은 내가 정합니다
키트에 정해진 그림체는 없습니다. 아래 셋 중 편한 방법으로 정하면 됩니다.

| 방법 | 하는 일 |
|---|---|
| **참고 이미지** (가장 정확) | 원하는 그림체의 이미지 1~5장을 `brand/style_refs/` 폴더에 넣거나 채팅에 붙입니다 |
| **말로 설명** | "두꺼운 먹선에 탁한 색 만화풍", "수채화 그림책", "판화", "3D 클레이" 처럼 말합니다 |
| **맡기기** | Claude 가 대본을 보고 서로 다른 방향 3가지를 제안합니다 |

순서: 방법 선택 → Claude 가 화풍을 글로 정리 → **시안 3장**(대표 인물, 대표 장소, 대표 소품) 생성 → 내가 보고 OK 또는 수정 요청("선을 더 굵게", "색을 더 밝게") → 확정.
확정된 스타일은 저장되어 다음 영상에도 그대로 쓰입니다. 바꾸고 싶으면 "그림 스타일 다시 정하자"고 하면 됩니다.

- 참고 이미지는 **그림체만** 참고합니다. 그 이미지 자체나 똑같은 구도가 영상에 들어가지 않습니다.
- 다른 채널의 고유 캐릭터나 실존 인물의 얼굴을 그대로 따라 그리게 하지 마세요.
- 키트에는 완성 영상의 장면 예시를 넣지 않았습니다. 화면 구성은 매번 내 대본에서 새로 짭니다. 원하는 화면 느낌이 있으면 참고 채널이나 캡처를 주세요.

## 영상 한 편 만드는 순서
| 단계 | 내가 하는 일 | Claude Code 에 하는 말 |
|---|---|---|
| 1 | 대본을 주고 질문에 답하기 | "새 영상 만들자. 이름은 ○○. 대본은 이거야" |
| 2 | 만들어진 음성 들어 보기 | "음성 만들어줘" → 어색한 곳이 있으면 "○○ 부분 이렇게 고쳐줘" |
| 3 | **장면 계획과 그림 목록을 보고 승인** | "구간 나누고 필요한 그림 목록 보여줘" → "좋아, 생성해" |
| 4 | 그림 시트를 보고 의견 주기 | "○○ 그림은 다시, 더 ○○하게" |
| 5 | **앞 1~2분을 보고 방향 확인** | "앞부분 먼저 만들어서 보여줘" → "좋아, 나머지도 진행해" |
| 6 | 완성본을 보고 수정 요청 | "1분 31초에 글자가 겹쳐", "s07 에서 ○○ 바꿔줘" |

완성 파일은 `projects\○○\out\○○_final.mp4` 에 있습니다.

## 꼭 지킬 것
- **3단계와 5단계의 확인은 건너뛰지 마세요.** 음성, 그림, 배경음 생성에는 비용이 듭니다. 앞부분에서 방향을 맞추면 뒤에서 다시 만들 일이 줄어듭니다.
- 수정은 **"몇 분 몇 초"** 또는 **장면 번호**로 말하세요. 캡처 이미지를 같이 주면 더 정확합니다.
- Claude 는 영상을 재생해 볼 수 없습니다. 프레임은 확인하지만 **움직임과 소리는 직접 봐야 합니다.**
- 화면에 나온 숫자가 대본에 있는 사실인지 마지막 보고에서 확인하세요.
- 비밀번호는 Claude 에게 알려 주지 마세요.

## 자주 생기는 문제
| 증상 | 해결 |
|---|---|
| `python` 을 찾을 수 없다고 나옴 | 윈도우: Python 을 다시 설치하며 PATH 를 체크. 맥: `python3` 으로 실행 |
| 점검에서 API 키가 `[문제]` | `API키_양식.txt` 를 다시 채워 "이 파일로 키 등록해줘" |
| 그림이 참고 이미지와 너무 다름 | "그림 스타일 다시 정하자" → 참고 이미지를 더 주거나 다른 점을 말로 설명 |
| 목소리가 영어식으로 굴려 읽음 | "○○ 을 한국식으로 읽게 해줘" (읽는 법 사전에 등록됩니다) |
| 배경음이 안 들어감 | 일레븐랩스 키가 필요합니다. 없으면 음악 파일을 주고 "이걸 배경음으로 넣어줘" |
| 설치가 꼬인 것 같음 | `setup.bat`(맥은 `setup.command`)을 다시 실행. 만든 영상은 지워지지 않습니다 |

## 폴더 안내
- `projects/`: 영상별 작업 폴더 (대본, 음성, 그림, 장면 코드, 결과물)
- `brand/`: 내 채널 설정과 그림 스타일 (`style_refs/` 에 참고 이미지)
- `examples/`: 짧은 시험 영상 두 편의 코드. Claude 가 함수 쓰는 법만 참고합니다.
- `engine/`, `tools/`, `templates/`, `mgp.py`: 프로그램 본체. 건드리지 않습니다.
- `fonts/`: 무료 배포 글꼴 (출처와 라이선스는 `fonts/LICENSE.txt`)
