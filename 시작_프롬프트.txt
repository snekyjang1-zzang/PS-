[모션그래픽 키트 v4 — Claude Code 에 처음 한 번 붙여 넣는 글]

사용법
1. 이 폴더(mg-pipeline)에서 Claude Code 를 엽니다.
2. API키_양식.txt 에 본인 키를 적어 저장합니다. (키를 채팅창에 직접 붙여 넣지 마세요)
3. 아래 줄부터 끝까지 복사해서 Claude Code 에 붙여 넣습니다.

------------------------------------------------------------

이 폴더는 대본으로 모션그래픽 영상을 만드는 키트야. 먼저 CLAUDE.md 와 .claude/skills/motion-graphics/SKILL.md 를 끝까지 읽고, 거기 적힌 순서와 규칙을 그대로 따라 줘.

지금 할 일은 아래 순서야. 각 단계가 끝나면 한 줄로 알려 주고 다음으로 넘어가.

1. 설치: `python mgp.py doctor` 로 점검하고, 설치가 안 돼 있으면 `python mgp.py setup` 을 실행해 줘. (맥이면 python3)
2. API 키 등록: 이 폴더의 `API키_양식.txt` 에 내 키를 적어 뒀어. `python mgp.py keys --from "API키_양식.txt"` 로 등록해 줘. 이 파일을 직접 열어 읽지는 마. 등록되면 `doctor` 로 확인하고, 그 txt 파일은 지워도 되는지 나한테 물어봐 줘.
3. 채널 프로필: 내 채널에 대해 필요한 것을 선택지와 함께 3~4개씩 물어봐 줘.
4. 그림 스타일: 스킬의 "⓪-C 그림 스타일 정하기" 순서대로 진행해 줘.
   - 내가 원하는 그림체의 참고 이미지를 brand/style_refs/ 폴더에 넣어 뒀거나, 지금 채팅에 붙여 줄 거야. 없으면 말로 설명할게. 어떻게 정할지부터 물어봐 줘.
   - 화풍을 글로 정리해서 보여 주고, 시안 3장(대표 인물, 대표 장소, 대표 소품)을 만들기 전에 몇 장이 생성되는지 알려 준 뒤 내 승인을 받아 줘.
   - 시안을 보고 내가 OK 하면 그 스타일로 확정해 줘. 참고 이미지는 화풍만 참고하고 영상에 그대로 쓰지 마.
5. 첫 영상: 내가 대본을 주면 스킬의 ① ~ ⑦ 순서대로 만들어 줘.
   - 돈이 드는 단계(음성, 그림, 배경음·효과음)는 실행하기 전에 분량을 알려 주고 내 승인을 받아 줘.
   - 긴 영상은 앞 1~2분을 먼저 만들어 보여 주고, 내가 방향을 확인한 뒤 나머지를 만들어 줘.
   - 렌더하기 전에 `python mgp.py check` 로 모든 컷을 그려 보고, 겹침·잘림·빈 화면을 네가 먼저 고쳐 줘.
   - 완성하면 영상 파일 위치, 확인한 것과 확인하지 못한 것(움직임·소리), 내가 봐야 할 곳을 정리해 줘.

지금은 1번부터 시작해 줘.
