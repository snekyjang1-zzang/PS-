# 채널 공용 (brand/)
- `channel.json`: 채널 프로필. Claude가 처음 한 번 물어서 채운다(분야, 분위기, 참고, 마스코트, 목소리, 자막, 구독 멘트, 썸네일 형식, 피할 것). 새 프로젝트의 기본값이 된다.

## 마스코트
이 키트에는 마스코트가 들어 있지 않다. 채널 캐릭터를 두고 싶으면 Claude에게 "마스코트 만들자"고 하면 된다
(어떤 캐릭터로 할지 묻고 → 후보 3종 → 고른 것으로 표정·포즈 세트 생성 → 이 폴더에 `<이름>_<포즈>.png`로 저장 → `channel.json`의 `mascot`에 이름 기록).
- 표준 포즈: idle, point, shrug, shock, think, peek, facepalm, ew (상반신), full (전신). 영상 주제에 맞는 복장 버전을 더 만들어도 된다.
- 장면에서는 `mascot(C, '포즈', x, y, 높이, t, 등장시각, say='대사')`로 장면 안에 크게 세운다. `mascot`이 비어 있으면 아무것도 그려지지 않는다.

## 그림 스타일
- `style_refs/`: 원하는 그림체의 참고 이미지를 여기에 넣는다(1~5장). Claude가 보고 화풍을 글로 옮겨 시안 3장을 만든다. 참고 이미지는 화풍만 빌리며 영상에 그대로 쓰지 않는다.
- 승인한 시안은 `style_char.png`, `style_bg.png`, `style_prop.png`로 이 폴더에 저장되고, 이후 모든 그림이 이 3장을 기준으로 만들어진다. 화풍 문장은 `channel.json`의 `visual_style`.
- 스타일을 바꾸고 싶으면 Claude에게 "그림 스타일 다시 정하자"고 하면 된다.
